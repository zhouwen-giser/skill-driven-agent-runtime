# G05：三层 Outcome Judge 与单一终态权威

## 依赖

```text
G04
```

## 目标

实现 Task/Skill/User 三层 Judge，删除 WorkflowController 的 User Goal/A2A 终态能力，由 UserGoalPlanController 唯一提交。

## 范围

- TaskGoalCompletionContract；
- 三层Judge；
- WorkflowExecutionOutcome；
- UserGoalPlanController；
- Terminal Repository/A2A Projection。

## 必须完成的修改

1. Task节点生成TaskGoalContract。
2. Provider终态触发TaskGoalJudge。
3. Workflow只输出WorkflowExecutionOutcome。
4. SkillGoalJudge聚合Attempts。
5. UserGoalJudge按Coverage聚合。
6. 规则优先，Semantic受限。
7. 低置信度不得achieved/none。
8. UserGoalPlanController唯一Terminal。
9. DB唯一约束和authority元数据。
10. 删除旧Terminal接口/调用。

## 禁止事项

- 不改变冻结架构；
- 不用 TODO 或 Mock 代替产品实现；
- 不修改 Provider 项目；
- 不修改无关功能。

## 验证

- Task completed/Goal not achieved。
- Task failed/Effect achieved。
- Workflow completed/Skill Goal not achieved。
- Skill Goal achieved/User Goal working。
- User Goal achieved/single terminal。
- terminal race。
- low-confidence fail closed。

## 证据交付

- Outcome matrix
- False-achieved report
- Terminal symbol audit
- Race evidence

## 完成合同

- 三层Judgment幂等；
- WorkflowController无A2A终态能力；
- UserGoalPlanController唯一权威；
- False Achieved=0。
