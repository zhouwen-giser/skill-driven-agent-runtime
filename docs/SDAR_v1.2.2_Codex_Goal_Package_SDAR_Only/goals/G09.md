# G09：Business Event Impact、Recovery 与 UserGoalPlan Revision

## 依赖

```text
G06；G08
```

## 目标

把 Task/Resource Event 映射到 Workflow、Attempt、SkillGoal、UserGoalPlan 和 User Criterion，并执行有界处置。

## 范围

- TaskImpactAssessmentService；
- SkillGoalPlanImpactService；
- Event Recovery；
- EventHandlingSkillGoal；
- Incident AgentTask；
- Emergency Skill；
- Audit/API。

## 必须完成的修改

1. 实现taskId→Binding→Attempt→Goal→Plan映射。
2. Resource Event组合Provider Relation和本地Binding。
3. 规则优先Impact。
4. Semantic使用受限LLM。
5. 低置信度禁止none。
6. Task/Goal/Dependency/Plan Assumption路由。
7. 插入EventHandlingSkillGoal。
8. 跨Goal创建Incident并去重。
9. Continuity Loss保守Recovery。
10. Emergency Skill只隔离。
11. 所有自动动作经过Policy/Confirmation。

## 禁止事项

- 不改变冻结架构；
- 不用 TODO 或 Mock 代替产品实现；
- 不修改 Provider 项目；
- 不修改无关功能。

## 验证

- related/no impact。
- current/future goal。
- evidence invalidation。
- relation incomplete。
- continuity。
- handling goal。
- incident dedupe。
- LLM low confidence。
- event/task notification race。

## 证据交付

- Impact matrix
- Rule/LLM boundary
- Recovery trace
- Incident evidence

## 完成合同

- Provider关联不被当作影响权威；
- Impact可追踪到User Criterion；
- 自动处置有界；
- No Replay保持；
- G10可进行真实Interop。
