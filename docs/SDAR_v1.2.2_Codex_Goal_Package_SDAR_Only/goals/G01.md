# G01：删除 Legacy 产品路径

## 依赖

```text
G00
```

## 目标

删除 Legacy MCP、旧 Skill Projection、旧 Goal Terminal 控制路径，使仓库只保留 v1.2.2 产品模型。

## 范围

- Legacy transport/router/config；
- Legacy Skill projection；
- 旧 GoalEvaluator terminal route；
- 旧 Management/Console mode；
- Legacy tests/docs。

## 必须完成的修改

1. 搜索所有 Legacy 符号和分支。
2. 删除 `/mcp/legacy` 和 mode switch。
3. 删除旧 Skill 自动投影。
4. 删除旧 Terminal Sink/API。
5. 更新架构门禁，禁止 Legacy 引用。
6. 创建 clean-slate ADR。
7. 调整测试为唯一新模型。

## 禁止事项

- 不删除 Frozen MCP Tasks V1.0；
- 不保留“暂未使用”的 Legacy 分支；
- 不增加历史数据 Adapter；
- 不修改 Provider 项目。

## 验证

- Format/Lint/Typecheck/Build。
- Legacy symbol grep 为零。
- Architecture Gate。
- Frozen MCP Tasks 主线回归。

## 证据交付

- Legacy removal report
- Deleted symbols
- Architecture evidence

## 完成合同

- 产品代码无 Legacy 入口；
- 无 Legacy Skill Projection；
- 无旧 Terminal 产品调用；
- 代码可编译；
- G02 不需兼容层。

更新 Master ExecPlan，并将提交、测试、证据、阻断和权威输出交给下一 Goal。
