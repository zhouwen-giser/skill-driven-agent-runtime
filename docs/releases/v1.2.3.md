# SDAR v1.2.3 Release Notes

SDAR v1.2.3 adds a governed cognitive planning plane around the unchanged v1.2.2 execution,
Outcome, Recovery and Business Events authorities. Online tasks can understand ambiguity, clarify and
confirm Goal Contracts, review/patch plans, then hand only confirmed work to v1.2.2. Offline learning
captures immutable Episodes, Observations and Candidates, then requires Replay/Shadow and governed
Promotion before Active knowledge can be retrieved.

The release defaults are conservative: Capture/Observer are enabled, induction and injection are
shadow, Promotion and interaction are manual, and automatic active use is limited to explicitly
reviewed low-risk knowledge. Replay has no physical Provider/MCP/device side effects.

Operational additions include deterministic Capability Summary/Public Card snapshots, interactive
Goal/Planning sessions, Experience/Knowledge governance, bounded Active-only retrieval, complete
usage lineage, cognitive Management/Console/A2A views, reproducible Promotion reports and startup
reconciliation.

Verification evidence is in [release-report.md](../../reports/v1.2.3-release/release-report.md) and
[G17 completion](../../reports/goal/g17-completion.md). The trusted-intranet/no-auth V1 warning remains.
There is no Python sidecar, no second workflow runtime and no cognitive automatic Skill publication.
