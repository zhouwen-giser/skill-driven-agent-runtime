## 必须完成的实施任务

1. 在 v1.2.2 事实提交事务中写 Outbox，不在主链同步调用 Observer。
2. 实现 Episode Eligibility：Contract、Current Plan、User Goal Judgment 和 Authority 完整。
3. 实现 PostgreSQL Lease、attempt、backoff、dead letter 和 reconciler。
4. 实现 Episode Builder，组装 Plan Revision、Attempt、Outcome、Progress、Recovery、Event Impact 和 Interaction。
5. 实现 Redaction、Source Kind、Completeness、Episode Hash 和不可变 Revision。
6. 实现 at-least-once Worker + Handler Idempotency。
7. Redis 丢失后从 PostgreSQL Job/Outbox 重建。
8. 引入 Gemini CLI 小型安全/调度算法时登记源 commit、修改说明和 Apache NOTICE。

## 实施细则

- 先审计当前仓库符号和测试，禁止创建重复服务或第二权威；
- 所有新 Domain 对象必须有 factory/validator、immutable snapshot 和明确 error code；
- 所有模型输出必须使用 Zod/JSON Schema，并由确定性 Application 代码校验；
- PostgreSQL 写入必须定义事务、CAS/幂等和重启语义；
- Redis/BullMQ 数据必须可由 PostgreSQL 重建；
- 适合时先加入失败测试，再完成实现；
- 更新 OpenAPI、Acceptance Map、Architecture、Migration 和 Console（如本 Goal 涉及）；
- 不允许 TODO、空实现、仅接口或只在测试环境生效的产品路径。

## 禁止事项

- 不改写 v1.2.2 Goal/Skill/Outcome/Recovery Authority；
- 不让 LLM 直接写权威状态；
- 不保存私有思维链；
- 不引入 Python Sidecar 或文件型知识权威；
- 不让 Candidate 绕过 Promotion；
- 不自动发布 Skill；
- 不删除失败测试或降低冻结验收标准；
- 不修改与本 Goal 无关的功能，除非为修复真实架构阻断并记录 ADR。

## 验证

- Goal Terminal 后异步创建 Episode。
- 同一事实重复投递不重复 Episode。
- 缺关键事实进入拒绝/等待，不生成默认经验。
- Worker 崩溃、Redis 清空、PostgreSQL 重启后恢复。
- Episode 不包含凭据和私有思维链。

最低还必须运行受影响范围的 format、lint、typecheck、unit、contract、integration 和 build；最终完整 `pnpm verify` 在 G17 执行。
