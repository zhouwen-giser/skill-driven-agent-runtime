## 必须完成的实施任务

1. 实现 Public Visibility Allowlist，不使用 Denylist。
2. 由 Runtime Capability Summary 生成 Public Capability Profile。
3. 生成稳定顶层 Description；LLM Narrative 仅作为可选展示产物。
4. Narrative 失败时使用确定性模板。
5. 实现 `catalogHash + generationPolicyVersion` 绑定和 Active Card Pointer。
6. 将当前 `skills[]` 投影保留为 Enabled Public Skill 明细。
7. 增加可选 `io.sdar/capabilityProfile` Extension。
8. A2A 请求只读取已激活 Snapshot，不在请求时调用 Model。

## 实施细则

- 先审计当前仓库符号和测试，禁止创建重复服务或第二权威；
- 所有新 Domain 对象必须有 factory/validator、immutable snapshot 和明确 error code；
- 所有模型输出必须使用 Zod/JSON Schema，并由确定性 Application 代码校验；
- PostgreSQL 写入必须定义事务、CAS/幂等和重启语义；
- Redis/BullMQ 数据必须可由 PostgreSQL 重建；
- 适合时先加入失败测试，再完成实现；
- 更新 OpenAPI、Acceptance Map、Architecture、Migration 和 Console（如本 Goal 涉及）；
- 不允许 TODO、空实现、仅接口或只在测试环境生效的产品路径。

## 禁止事项

- 不改写 v1.2.2 Goal/Skill/Outcome/Recovery Authority；
- 不让 LLM 直接写权威状态；
- 不保存私有思维链；
- 不引入 Python Sidecar 或文件型知识权威；
- 不让 Candidate 绕过 Promotion；
- 不自动发布 Skill；
- 不删除失败测试或降低冻结验收标准；
- 不修改与本 Goal 无关的功能，除非为修复真实架构阻断并记录 ADR。

## 验证

- Card 不含 Tool、Provider、Credential、Workflow、内部 Skill、用户经验和实时资源。
- Hash 不匹配时拒绝激活。
- Narrative 失败仍可服务 Agent Card。
- A2A Baseline/TCK 不回归。

最低还必须运行受影响范围的 format、lint、typecheck、unit、contract、integration 和 build；最终完整 `pnpm verify` 在 G17 执行。
