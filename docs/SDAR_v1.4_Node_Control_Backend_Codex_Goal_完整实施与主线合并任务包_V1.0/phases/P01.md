## 工作

2. 独立 Control PostgreSQL 连接与 Migration Ledger。
3. Node Identity/Profile、Health/Ready、ManagementOperation、Audit 基础。
4. Dependency/Architecture Gate，禁止 Control 与 Runtime DB 交叉写。
5. 进程独立启停和 Compose/Environment 配置。
6. Node Control OpenAPI 最小真实 HTTP Vertical Slice。

## 验收
- 停止 Node Control 不停止 Runtime。
- Fresh Control DB 可创建。
- Architecture Gate 通过。
- API/Worker Build 和 Smoke 通过。
