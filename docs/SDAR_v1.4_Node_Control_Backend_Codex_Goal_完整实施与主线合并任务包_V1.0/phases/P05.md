## 工作
1. Direct 与 SMPP Origin 的 Candidate/Import/Binding。
2. MCP server/discover + tools/list 作为 Catalog 权威。
3. Catalog Revision/Checksum/Drift、Availability Freshness。
4. Suspend/Remove 只阻止新选择，不自动取消已有 Remote Task。
5. Endpoint/CredentialRef 安全与 SSRF Allowlist。
6. 复用现有 MCP Adapter，不复制 SDK 类型到 Domain。

## 验收
- Telemetry 不可注册 Provider。
- Snapshot 不可直接认定 Tool 可调用。
- Drift/Availability Expiry 阻止新选择。
- 已有 Task 可按原 Binding 查询/控制。
