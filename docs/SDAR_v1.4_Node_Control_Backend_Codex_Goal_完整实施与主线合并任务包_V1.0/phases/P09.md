# P09 — Task Capability Binding 与 Attempt

## 建议实施提交

```text
feat(v1.4-p09): bind tasks to immutable capabilities
```

证据提交：

```text
docs(v1.4-p09): record completion evidence
```

## 工作
1. Task 接受事务内创建 immutable TaskCapabilityBinding。
2. 快照 Capability/Exposure/Input/Success/Evidence/Constraints/Provider Policy。
3. 创建 TaskCapabilityExecutionAttempt。
4. Replan/Skill Switch/Provider Failover/Recovery 新增 Attempt，不改 Binding。
5. Capability Resolution/Admission Guard。
6. Terminal = Workflow Complete + Success Criteria + Required Evidence。
7. 与现有 AgentTask/A2A/Goal Authority 原子对齐。

## 验收
- Task Created/Binding/Initial Transition 同事务。
- 失败回滚无孤儿 Task 或 Binding。
- Attempt History 完整。
- Workflow Complete 不能单独完成 Capability。
