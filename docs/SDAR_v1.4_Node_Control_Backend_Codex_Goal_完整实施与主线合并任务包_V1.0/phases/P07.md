## 工作
1. Runtime 计算 CapabilityReadinessSnapshot。
2. 输入包含 Definition/Binding/Skill/Template/Catalog/Availability/Model/Policy/Maintenance/Kill Switch。
3. 状态 available/degraded/unavailable/suspended。
4. 事件驱动、TTL、迟滞、最小稳定窗口。
5. Snapshot 持久化与重启恢复。
6. Control Plane 只读和请求重算，不直接写状态。

## 验收
- Availability 过期会降级/不可用。
- 抖动不会产生不受控翻转。
- Runtime 是唯一 Readiness writer。
- Snapshot Hash/Freshness 可审计。
