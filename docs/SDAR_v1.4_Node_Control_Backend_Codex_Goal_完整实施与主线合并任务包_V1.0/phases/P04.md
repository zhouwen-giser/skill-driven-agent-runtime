## 工作
1. SmppRegistrySource、Snapshot、Revision、Checksum、ETag、Watch、LKG。
2. 支持多个 SMPP Source 和稳定复合身份。
3. Bootstrap/Latest/Watch 只触发刷新。
4. Snapshot Apply 原子化，过期/回退/漂移可见。
5. SMPP 不可用时使用本地 LKG，不清空 Provider。
6. 不把 Snapshot 当作 Tool Catalog 或 Availability 权威。

## 验收
- 相同 Provider ID 跨 Source 隔离。
- 坏 Snapshot 不覆盖 LKG。
- SMPP outage 不影响已运行 Task。
- Revision/Checksum/ETag 合同通过。
