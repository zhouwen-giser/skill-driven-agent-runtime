# 01. 产品范围与非目标

## v1.4 一期范围

- Node Identity、Version、Health；
- Configuration Revision；
- LLM Provider、Model Route；
- SMPP Registry Source；
- MCP Provider Candidate、Binding、Catalog Drift；
- Skill 治理入口；
- Plan Template / Artifact 治理入口；
- Node Capability Definition 和 Implementation Binding；
- Capability Readiness；
- A2A Exposure 和 Agent Card Revision；
- Task/Capability Binding 查询及受控任务命令；
- Evidence Export 配置、投递水位和错误；
- Management Operation、Audit、Node Events；
- Runtime Bootstrap、Revision Pull/Watch、Apply/Ack/LKG。

## 非目标

- 正式控制台前端；
- 分层自治组织网络控制平面；
- 多节点聚合、层级目标委托和跨节点资源仲裁；
- 遥测数据观测、趋势、评价和对账；
- Telemetry Query Proxy；
- Provider 业务流量代理；
- Runtime Task 表编辑；
- 复杂企业 IAM；
- 公网 API 安全认证产品化。
