# v1.0.10 Feature Gate

Capability gap is now the terminal result of the current A2A Task. The old Task cannot resume or be mutated; A2A returns `FAILED` with structured evidence and directs the caller to register capability and submit a new Task. The active Goal remains available to that normal same-Context successor.
