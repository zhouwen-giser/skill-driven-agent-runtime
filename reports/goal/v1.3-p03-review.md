### Major closures verified

1. **Mining identity, coalescing and rate limiting (Review 2 Major 1).**
   `PostgresCompilationRunRepository.createProcessMiningRun` now accepts
   `sourceEventIds: readonly string[]` and rejects batches larger than 1,000 source events
   (`EXPERIENCE_COMPILATION_TRIGGER_BATCH_TOO_LARGE`). Batch identity is
   `stableId('source-event-batch', canonicalJson(eventIds))`, independent of event timestamps; the
   idempotency key is `process-mining:${cohortFingerprint}:${batchIdentity}`. A per-tenant/TaskType
   advisory lock (`pg_advisory_xact_lock(hashtextextended('process-mining-trigger:${tenantId}:${taskTypeId}',0))`)
   guards a recent-run check that skips creation when an active or recent run exists
   (`status IN ('pending','leased','retry_wait') OR created_at > clock_timestamp() - interval '60 seconds'`).
   `ExperienceCompilationTriggerDispatcher.dispatch` passes `trigger.triggerIds` and `this.#clock.now()`
   instead of `trigger.occurredAt`, so two events at the same timestamp no longer collide and every
   Trace no longer schedules a full-cohort run.

2. **Mining/Brotli no longer block the Server event loop (Review 2 Major 2).**
   `experience-compilation-repositories.ts` replaced `brotliCompressSync` with
   `promisify(brotliCompress)` (`brotliCompressAsync`); `encodePatternDefinition` is now awaited.
   `BullMqCompilationWorker` sets `concurrency: runType === 'process_mining' ? 1 : 4` and
   `service.claim(workerId, runType === 'process_mining' ? 1 : 10)`, so production mining is
   single-concurrency. `DeterministicProcessMiner.discover` is now `async` and calls
   `yieldForOnlineRuntime(index)` which `await setImmediate` every 128 traces
   (`if (index === 0 || index % 128 !== 0) return`), yielding the event loop between batches.

3. **`task_request` SourceRef and nonempty `goal_created.authorityRefs` (Review 2 Major 3).**
   `experience-normalizer.ts` emits `sourceKind: 'task_request'` with `sourceRefs` on the
   `goal_created` event. `PostgresExperienceRepository` Fact Reader calls
   `addSource(sources, 'task_request', task, 'taskId', 'task-unknown', 1)`. The integration test
   `repositories.integration.test.ts` queries
   `jsonb_array_length(event->'authorityRefs')` for the `goal_created` event and asserts
   `task_source_authorities` is greater than zero.
