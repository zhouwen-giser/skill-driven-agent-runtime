## Review 2 — `1f7e043674081c2c8795e7ba6d142808abc6ff01`

Verdict: `REJECTED`

Findings: 0 Blocking / 3 Major / 0 Minor.

### Major

1. Automatic mining used `cohortFingerprint + occurredAt` identity. Two source events at the same
   timestamp could collide without consuming the second event, and every Trace scheduled another
   full-cohort run without durable coalescing/rate limiting.
2. Mining and quality-11 Brotli compression ran synchronously in the Server event loop. Asynchronous
   BullMQ delivery did not prevent the same Node process from blocking online HTTP/A2A work.
3. The formal Fact Reader returned the Task snapshot but did not add its `task_request` SourceRef, so
   `goal_created.authorityRefs` was empty in the product vertical.

### Confirmed closures

- Real 10,000-trace PostgreSQL lossless persistence passes.
- Formal Episode→Server Runtime→BullMQ→Trace→Pattern composition is reachable.
- Terminal lease exhaustion, strict nested Schema, real Redis loss/rebuild and tenant-scoped Pattern
  reads pass.
- Quantitative DB/worker/queue evidence is present.
- No P04, Artifact, Skill, Template, Gateway or Python sidecar scope drift was found.
- The default `/sdar` infrastructure smoke failure is an external evidence-environment blocker, not
  a P03 implementation defect.

### Remediation in progress

- Process-mining triggers now carry a sorted source-event batch, coalesce by cohort, use an advisory
  lock and enforce one active/recent run per tenant/Task Type with a 60-second durable rate window.
  Batch identity is independent of event timestamps and is bounded at 1,000 source events.
- Production mining concurrency is one. Deterministic mining yields every 128 traces and Brotli uses
  asynchronous libuv compression so CPU/compression does not monopolize the Server event loop.
- Formal Fact Reader source inventory now includes `task_request`; the Server vertical asserts a
  nonempty `goal_created.authorityRefs`.

Focused typecheck and 5-file / 34-test regression are green. Real PostgreSQL/Redis integration and a
new independent re-review remain required before this record can become accepted.
