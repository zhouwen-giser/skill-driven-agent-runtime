## Implementation Summary (G07 + G08)

### G07 — Pattern Generalization

- **Domain contracts** (`packages/domain/src/compiler/artifact-candidate-generation.ts`): `FusedPattern`, `GeneralizedPattern`, `CandidateStaticValidationResult` with frozen 1.1 schema hashes matching `CONTRACT-LOCK.json`. Nested types: `StructuralPattern`, `SemanticPatternCandidate`, `ApplicabilityCandidate`, `GeneralizedVariable`, `Invariant`, `ValidationIssue`. Strict factories with content-hash helpers.
- **Pattern Fusion** (`packages/application/src/compiler/pattern-generalization.ts`): `PatternFusionService` fuses P03 structural facts with v1.2.3 Task Type/Capability/Goal/Outcome facts and optional LLM semantic candidates. Structural facts are never overwritten by LLM output. `NoOpSemanticModel` provides a no-op default. Contradiction evidence is retained, not averaged.
- **Generalization** (`PatternGeneralizationService`): abstracts instance fields into variables, invariants, required and forbidden conditions. Anti-overfitting rules enforced: no single-device globalization, no cross-user preference hardening, no temporary-auth hardening, no one-success universal pattern, no failure-boundary deletion.

### G08 — Plan Template Candidate Compiler

- **Candidate Generator** (`packages/application/src/compiler/candidate-generator.ts`): `ArtifactCandidateGenerator` maps `GeneralizedPattern` → `CompiledArtifact` with `status=candidate`, `artifactType=plan_template`, `riskLevel=medium`. Candidate fingerprint computed from 7 inputs for duplicate detection. Complete lineage referencing P03 outputs (WorkflowPattern, DiscoveredProcessPattern, FusedPattern, GeneralizedPattern).
- **Plan Template Compiler** (`PlanTemplateCompiler`): step classification (action/observation/reasoning/verification/recovery/human_gate), capability mapping (Capability IDs, not Skill IDs), Skill Goal DAG (acyclic, no dangling references), parameter extraction (trust levels, allowed sources), completion contract template (criteria referencing goal pattern criteria), recovery branches (`sideEffectReplayPolicy=forbidden`).
- **Static Validator** (`CandidateStaticValidator`): schema, DAG, criteria coverage, capability shape, parameter policy, replay safety, bounds, and duplicate fingerprint validation. `passed_static` is explicitly not a promotion signal.
- **Persistence** (`packages/persistence-postgres/src/compiler/candidate-generation-repositories.ts`): `PostgresCandidateGenerationRepository` saves GeneralizedPattern, fingerprint, and validation. Candidate persistence reuses P02 `ArtifactRepository.saveCandidate`.
- **Migration** (`infra/postgres/migrations/0127_v13_artifact_candidate_generation`): adds `generalized_pattern`, `candidate_fingerprint`, `candidate_static_validation`, `candidate_generation_run`, `candidate_model_invocation` tables as non-authoritative children.
- **Worker** (`packages/runtime-redis/src/compiler/candidate-generation-workers.ts`): wake-only BullMQ worker for `sdar-compiler-pattern-generalization` and `sdar-compiler-artifact-generation` queues.
