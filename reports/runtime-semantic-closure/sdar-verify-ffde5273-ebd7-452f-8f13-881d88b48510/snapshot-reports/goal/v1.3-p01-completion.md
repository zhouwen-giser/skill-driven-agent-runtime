## Outcome

P01 implements the frozen Runtime Artifact Domain as immutable, bounded pure data. It includes all
five Artifact definition kinds, the complete status vocabulary, guarded lifecycle transitions,
applicability and dependency snapshots, deterministic conditions, lineage, rebuildable runtime
bindings, Zod and JSON Schema contracts, a five-kind golden fixture, and an architecture guard.

P01 adds no database table, migration, repository, application service, queue, event, feature flag,
HTTP/API operation, Console surface, MCP/A2A adapter, Provider call, Skill execution, or LangGraph
execution path.

## Why these fields belong to Domain

- Identity, version, type, scope, definition, risk and status establish aggregate meaning independent
  of storage or transport.
- Applicability, capability/policy requirements and dependency snapshots are deterministic
  preconditions that adapters must not reinterpret.
- Lineage and validation references preserve provenance and governed activation evidence.
- `contentHash` and immutable timestamps support version identity and audit without making a database
  or runtime authoritative.
- Runtime Binding describes a rebuildable projection; ADR-116 prevents it from becoming Artifact or
  active-pointer authority.
