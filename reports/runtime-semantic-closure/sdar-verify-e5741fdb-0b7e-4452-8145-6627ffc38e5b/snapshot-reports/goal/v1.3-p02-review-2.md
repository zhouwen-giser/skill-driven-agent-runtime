# SDAR v1.3 P02 Independent Review 2

- Reviewed commit: `ee521584318f1c7e3a25267b86728da1cf076747`
- Decision: `REJECTED`
- Blocking: 1
- Major: 2
- Minor: 0

The second independent read-only reviewer accepted closure of the first review's four Blocking,
six Major and one Minor findings, but rejected P02 completion because the shared Outbox delivery
contract and two projection invariants were still incomplete. No `COMPLETED` Handoff was emitted.

## Blocking finding

The Artifact projection startup consumer read unrelated Artifact events as no-ops and then set their
shared `published_at`. That could permanently hide execution, feedback or future-package events from
the actual publisher or another consumer.

## Major findings

1. Registry version cache invalidation covered activation/deprecation only. Validation start,
   validation completion, revalidation and rejected approval could leave a cached lifecycle status
   stale.
2. `artifact_lineage.created_at` was neither selected nor compared with the canonical envelope, so
   provenance-time projection drift was not detected.

## Required regression evidence

The next review must verify a consumer-private monotonic Outbox cursor that never claims shared
publication, lifecycle-wide version-cache invalidation, immutable and exactly checked Lineage
creation time, and real server startup with mixed handled and unhandled Outbox events. A new
independent reviewer must also confirm that all first-review closures remain intact.
