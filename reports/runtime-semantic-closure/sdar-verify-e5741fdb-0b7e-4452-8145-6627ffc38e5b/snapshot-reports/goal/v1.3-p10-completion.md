# SDAR v1.3 P10 Completion

Status: `COMPLETED`

P10/G17-G18 implements a feature-gated Fast Gateway that freezes trusted
request facts, enforces Auth -> Tenant -> Authorization -> Policy/Kill Switch,
delegates retrieval to P07, Rule evaluation to P09 and Template/formal handoff
to P08, and otherwise preserves the existing Cognitive Runtime path. It never
becomes Goal, Plan, Workflow, Outcome, Artifact lifecycle, authorization or
policy authority.

## G17 Fast Gateway

- Frozen V1.1 Domain contracts and portable JSON Schema match the P10 lock.
- Request entry is an optional `PlanPreparationProcessor` seam; feature-off
  behavior and A2A Task semantics remain unchanged.
- Deny terminates, confirmation enters formal interaction, no-match/degraded
  paths use the existing fallback, and formal handoffs require P08/P09 commit
  evidence.
- Absolute deadline, fallback reserve, cancellation, late-result discard,
  formal commit guards, per-adapter/fallback bulkheads, tenant/adapter/failure
  circuits and authority-preserving load shedding are implemented.
- PostgreSQL migration `0132_v13_fast_gateway` owns request, decision and
  feedback correlation plus transactional Outbox. Redis is not an authority.
- Management API, OpenAPI and Console expose bounded reason/stage/handoff/
  fallback evidence without raw request text, credentials or private reasoning.

## G18 Feedback, drift and revalidation

- `GatewayFeedbackEnvelope` uses a caller-stable idempotency ID and preserves
  formal Goal/Plan/Outcome only as references.
- Selected Artifact feedback is projected through P02 usage authority and a
  transactional `artifact.feedback_recorded` Outbox fact.
- Analysis separates fast selected, fast committed, fallback and formal
  outcome, aggregates by Artifact/Tenant/Task Type/Environment and preserves
  correction/recovery attribution.
- Drift thresholds are versioned and bounded; only P06 revalidation signals are
  emitted. P10 never changes Artifact status or active pointers.
- Actor deletion removes Gateway detail and its Gateway-owned Outbox rows in
  one PostgreSQL transaction.
