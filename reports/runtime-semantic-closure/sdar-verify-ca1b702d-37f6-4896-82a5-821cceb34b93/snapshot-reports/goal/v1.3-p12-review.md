# SDAR v1.3 P12 Independent Read-only Review

## Review phase

The review ran after the first implementation freeze. No code was changed during the phase.

## Blocking

- Runtime decisions joined `fast_gateway_request` with a nonexistent `gateway_request_id`. Closed by
  the exact `request_id` join and real PostgreSQL/Server regression.

## Major

- Formal Outbox producer names and frozen SSE names diverged; P10/P11 events also required tenant
  derivation from authoritative source rows. Closed by migration 0134 sequence coverage, explicit
  mapping and source-table joins.
- Cross-tenant evidence views returned 200 empty. Closed with indistinguishable 404.
- Task Type/drift filters were imprecise. Closed with exact JSONB membership and drift fact checks.
- A2A evidence was unconditional. Closed by binding it to optional P12 composition.
- Promotion-package commands bypassed the existing command ledger. Closed by the additive audited
  operation.
- `source_pattern_refs`, stale-version guidance, OpenAPI schemas and real runtime/SSE/IDOR coverage
  were incomplete. Closed by shared redaction, Console/OpenAPI changes and focused regressions.
- Architecture/report alignment was missing. Closed by ADR-122, Traceability, Status, Changelog,
  evidence reports and the living ExecPlan.

## Minor

- SSE is a bounded replay response, not a persistent subscription. Accepted and documented because
  it provides explicit limit/overflow/resume and cannot become state authority.

## Accepted

- P02-P11 authority remains unchanged.
- Formal A2A Task and input-required transitions are unchanged.
- Commands delegate to existing governance ports.
- Read audit is append-only and non-authoritative.

## Final verdict

Blocking: 0 open. Major: 0 open. Minor: 0 open. Accepted: 4.
