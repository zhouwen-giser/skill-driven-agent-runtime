# SDAR v1.3 P00 Architecture Dependency Map

## Authority path

```text
Confirmed Goal Contract + validated confirmed UserGoalPlan
  → existing v1.2.2 UserGoalPlanController (sole User Goal/A2A terminal authority)
  → immutable Workflow plan
  → sole LangGraph.js execution runtime
  → Outcome/Recovery/Business Events evidence in PostgreSQL
  → transactional Experience outbox
  → Episode → Observer/Typed Extractors → Reflector
  → Candidate Knowledge → Replay/Shadow/manual Promotion
  → Active-only retrieval
  → advisory Experience planner decorator
  → existing validator/confirmation/UserGoalPlanController authority
```

## Boundary findings

| Boundary | Authoritative owner | P00 finding |
| --- | --- | --- |
| User Goal/A2A terminal state | `UserGoalPlanController` + PostgreSQL transaction | intact; cognitive modules cannot commit terminal state |
| Workflow execution | LangGraph.js | sole runtime; cognitive sessions and Replay are data/evaluation paths |
| Experience facts and jobs | PostgreSQL outbox/job/lease | Redis carries rebuildable wakes only |
| Knowledge lifecycle | PostgreSQL Candidate/transition/Active records | model output cannot activate; initial/high-risk gates require human approval |
| Search projection | Active-only rebuildable projection | Candidate excluded; projection is not authority |
| Planner enrichment | `ExperienceEnrichedUserGoalPlanningService` decorator | fail-open to base planner; full validation and confirmation remain mandatory |
| Replay/Shadow | Application evaluation harness | zero physical Provider/MCP/device calls; cannot mutate formal Task/Plan |
| Protocol/UI | A2A and Management/Console adapters | projections only; no second state authority |

No second Agent, Planner, Workflow runtime, database authority, Memory authority, direct SQL business
writer, Python sidecar or automatic Skill publication path was found by the architecture gate.

## Invariants carried into P01

- P01 owns only Artifact Domain types and schemas; it may not add persistence, Registry or Runtime.
- External SDK types cannot cross adapter boundaries.
- v1.3 compiled artifacts must remain planning/decision data and cannot become executable source code.
- PostgreSQL remains the sole system of record; future child projections cannot become a second
  authority.
- Every later formal handoff must preserve the existing validator, confirmation, Goal-version lock and
  `UserGoalPlanController` boundary.
