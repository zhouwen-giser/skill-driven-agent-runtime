## G13 Active Index and Retrieval

P07 reads only P02 PostgreSQL `active` pointer candidates. The Level-0 index
projects immutable definition facts (task type, exact patterns, structured
hints and optional embedding reference), then loads an immutable definition
only after narrowing. It rechecks authoritative status before a decision.
The `ArtifactRegistryService` index cache is disposable; Redis, pgvector, FTS,
memory and semantic scores are never Artifact authority.

Exact, structured and thresholded semantic paths are recorded in every Match.
Ranking is deterministic and presentation-only: applicability, tenant,
authorization, feature flags, dependencies, capability readiness and policy
all remain hard gates. Near scores return an explicit ambiguity/adaptation
outcome rather than a random selection.

## G14 Applicability and Candidate Decision

The Domain evaluator executes a restricted condition AST. Required conditions
must hold, forbidden conditions block and optional conditions cannot grant
eligibility. Parameter binding preserves source, trust and confidence; a
critical parameter cannot use a model default, and a preference is allowed
only when low-risk and tenant/user scoped. Conflicts and missing required
parameters produce confirmation or fallback.

Dependency snapshots, persisted validator/promotion policy versions, current
capabilities, current Skill candidates and current provider readiness all
fail closed. Public Agent Cards and historical success cannot prove runtime
readiness. Policy/OOD/critical uncertainty/kill switch decisions override the
rank. The P02 match audit and `runtime_candidate_decision` child projection
persist matcher/policy snapshot hashes, stable reason codes and the selected
non-executable decision.

Dependency mismatch delegates to P06's atomic scheduler. It persists the
P02 Validation Run, revalidation Trigger and Outbox together; global Artifacts
pin their latest eligible passed P05 holdout dataset ID, version and hash.
P07 itself cannot mutate an Artifact lifecycle state.

## Scope and Security

P07 is an internal selection service only. It adds no public request entry,
Fast Gateway, Template Runtime, Goal/Plan/Attempt creation, or Skill/MCP/
Provider call. Tenant absence/mismatch, authorization denial, disabled mode,
feature-type flags and tenant allowlist all fail closed before selection.
