# v1.2.3 Cognitive Replay Evidence

`promotion-report.json` is a deterministic, versioned fixture artifact generated by:

```bash
pnpm build
node scripts/generate-promotion-report.mjs
pnpm verify:cognitive-replay
```

The fixture proves serialization, hashing, disjoint `mutate_dev`/`promotion_test` partitions,
Baseline/Champion/Candidate comparison, all required metrics, and the zero-call
`NoPhysicalProvider` boundary. Its one `improved` verdict is synthetic regression evidence, not a
claim about production model efficacy.

The product path reads immutable PostgreSQL Goal Experience Episodes referenced by Promotion
evidence, uses the current Capability Summary catalog hash, and stores one idempotent
`promotion_provenance_report` per exact Candidate revision. The first-release runtime evaluator is
deliberately conservative: Baseline, Champion and Candidate are neutral unless an explicitly
configured evaluator supplies validated results. Fewer than three complete cases produces an
`incubating` report and leaves Knowledge in `candidate`.

Replay never invokes a real Provider, MCP Tool or device. The persisted report is audit/evaluation
evidence only and cannot write Active Knowledge, formal Task state, Skill state, Outcome or Recovery.
