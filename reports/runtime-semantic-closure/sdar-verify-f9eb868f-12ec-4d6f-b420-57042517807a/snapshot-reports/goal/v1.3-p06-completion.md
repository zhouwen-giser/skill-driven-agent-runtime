## G11 Shadow Safety and Durable Runs

`ArtifactShadowRun` and `ArtifactShadowResult` are strict immutable contracts.
PostgreSQL owns enqueue, lease, stale discard, completion, retry/dead-letter,
evidence and the P02 parent `artifact_validation_run`; Redis/BullMQ carries only
run-ID wakes. Admission, worker start and immediately-before-persist all read
the current formal state and fail closed when the pins no longer match.

The evaluator is a projection compiler, not an executor. Its closed operation
allowlist accepts only immutable reads, candidate projection compilation and
comparison. A prohibited provider/MCP/Skill operation produces an unsafe result,
deprecates the artifact, removes the active pointer and writes a durable safety
revalidation trigger. Physical outcome remains unknown.

## G12 Promotion and Governance

Promotion evidence is reconstructed from durable P05 replay results and P06
formal/shadow facts; callers cannot supply coverage. The stored package binds
full policy definition/hash, validation/shadow/counterexample/dependency hashes,
derived coverage and reason codes. Insufficient coverage, single-device,
single-user preference, temporary authorization and unsafe evidence are rejected
by policy before any operator action.

Approval is trusted-operator only and immutable. Activation validates the exact
package/approval/hash/CAS tuple, writes the P02 `validation_summary_id`, active
pointer, activation record, audit and Outbox in one transaction. Critical
revalidation removes the pointer; a missing safe P05 source creates a linked,
failed/dead-letter revalidation record instead of a ghost wake.

## First Failures and Closure

1. A shared `/sdar` database had an incompatible legacy migration ledger. It
   was preserved; all P06 execution used the guarded `sdar_v122_p06_smoke`
   isolated baseline instead.
2. Promotion evidence initially queried non-existent replay table columns.
   Environment/device are now read from the immutable replay Case content.
3. Shadow completion initially left the P02 parent lease fields populated.
   Completion now clears all parent lease fields atomically.
4. Active artifact mapping initially lacked the persisted validation summary.
   Activation now stores the exact promotion validation reference and reads it
   from the database projection.
5. The architecture gate rejected a `node:crypto` import in the Domain layer.
   Canonical SHA-256 is now a tested pure Domain primitive with no runtime
   adapter dependency.
